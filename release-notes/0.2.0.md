## Quick menu: nine slots instead of five

There were five slots and six built-in actions — and a slot is the only place where an
action can be seen or edited, so "Clean up transcript" was out of reach. Now there are
nine, on keys `1`–`9`. Your own layout stays where you put it: the new keys are filled
only with actions that are not in the row yet, so nothing ends up on two keys at once.

## Fixes

- **Retry after an error** now rewinds the whole exchange. Before, it dropped the last
  entry in the history, which was the wrong one when the error came on a later round of
  edits — the question could end up duplicated.
- **The tool loop says when it runs out of rounds.** Applied edits stayed, the answer
  never came, and the chat just looked stuck.
- **Requests give up**: 120 seconds of silence in a stream, 300 seconds without one. Stop
  also works on the non-streaming path now, where the button used to do nothing.
- **On mobile the busy notice stops the edit when tapped.** There was no way to stop one
  there at all.
- **A refusal that mentions tools carries a hint** to turn them off in the settings —
  models without function calling answer with a bare "bad request".

## Rough edges

- **The chat history moved to `history.json`**, next to `data.json`. It used to live in
  the settings file, which was rewritten whole on every change. The move happens by
  itself on first load.
- **Context is picked by size, not by message count** — 24 000 characters of the recent
  conversation instead of "the last twenty messages", which could mean a page or a book.
- **Clearing the chat can be undone** from the notice that follows it.
- **Token usage survives a panel reload.**
- **An edit can be undone in a note that is no longer open.**
- **A clipped note context is said out loud** — both to the model, so it does not mistake
  the beginning for the whole note, and to you.
